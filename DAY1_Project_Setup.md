\# Day 1 — Project Setup and Requirements



\## Project Title

Real-Time Financial Fraud Detection Pipeline



\## Objective

The objective of this project is to build a machine learning-based pipeline that analyses financial transactions and identifies potentially fraudulent activity.



\## Initial Planning

\- Defined the project objective and scope.

\- Selected the synthetic PaySim financial transaction dataset for development and testing.

\- Identified the main technologies required for the pipeline.



\## Planned Technologies

\- Python and Pandas for data processing

\- Scikit-learn for machine learning

\- Apache Kafka for transaction streaming

\- Streamlit for the interactive dashboard

\- Prometheus and Grafana for monitoring and metrics



\## Expected Outcome

A demonstrable pipeline that processes transactions, generates fraud predictions, displays alerts, and provides monitoring dashboards.



\## Day 1 Deliverable

Project objective, requirements, dataset choice, technology stack, and initial implementation plan documented.
