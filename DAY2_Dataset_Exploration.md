\# Day 2 — Dataset Exploration and Understanding



\## Project Title

Real-Time Financial Fraud Detection Pipeline



\## Objective

Understand the financial transaction dataset and identify the information needed to develop a fraud detection model.



\## Dataset Overview

\- Dataset: PaySim synthetic financial transaction dataset

\- Total records: 6,362,620

\- Total columns: 11

\- Target column: `isFraud`

\- Transaction types include PAYMENT, TRANSFER, CASH\_OUT, DEBIT, and CASH\_IN.



\## Key Activities

\- Reviewed the dataset structure and available columns.

\- Identified transaction details, transaction amounts, and account balance fields.

\- Identified `isFraud` as the target variable for classification.

\- Examined the importance of understanding class imbalance in fraud detection.

\- Identified the need to explore fraud patterns before model training.



\## Initial Findings

\- Fraud detection is a binary classification problem.

\- Fraudulent transactions are much less common than legitimate transactions.

\- Transaction type, amount, and account balance changes are useful candidates for further analysis.



\## Day 2 Deliverable

Dataset overview, target-variable identification, initial observations, and preparation for detailed exploratory data analysis.



\## Next Step

Perform detailed exploratory data analysis and investigate transaction patterns associated with fraud.
